<h2>🛡️ AIris Security</h2>

<p><i>AI-Powered Vulnerability Assessment Platform</i></p>

<img src="https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white"/>

<img src="https://img.shields.io/badge/scikit--learn-F7931E?style=flat-square&logo=scikit-learn&logoColor=white"/>

<br><br>

AIris Security combines **four industry-standard security scanners** with a hybrid machine-learning engine to automate vulnerability assessment.

### Pipeline

```text
Target URL
    ↓
┌──────────────────────────┐
│ Nmap  •  Nikto           │
│ SSLScan • DirSearch      │
└──────────────────────────┘
    ↓
Hybrid ML Engine
    ↓
Risk Score 0–100
    ↓
Attack / CVE Context
    ↓
Professional PDF Report
```

### Highlights

* Four scanners executed in parallel
* XGBoost risk scoring
* TF-IDF + Logistic Regression payload classifier
* Scanner-evidence risk boosts
* Attack-type and CVE context
* Automated PDF reporting
* Severity charts and risk visualization
* Per-finding remediation guidance

<h2>🤖 Project ALISA</h2>

<p><i>Local-First AI Companion & Desktop Operating Layer</i></p>

<img src="https://img.shields.io/badge/Python-3670A0?style=flat-square&logo=python&logoColor=ffdd54"/>
<img src="https://img.shields.io/badge/Ollama-111111?style=flat-square&logo=ollama&logoColor=white"/>
<img src="https://img.shields.io/badge/PyTorch-EE4C2C?style=flat-square&logo=pytorch&logoColor=white"/>
<img src="https://img.shields.io/badge/OpenCV-5C3EE8?style=flat-square&logo=opencv&logoColor=white"/>

<br><br>

ALISA is a **local-first AI companion and desktop operating layer** designed to run primarily on your own hardware with no cloud dependency for its core assistant.

### Architecture

```text
Voice / Text
     ↓
Intent + Risk Router
     ↓
Context Builder
     ↓
Agent Coordinator
     ↓
LLM Planner
     ↓
Policy Gate
     ↓
Service Execution
     ↓
Verification Agent
     ↓
Response + Voice + Avatar
```

### Highlights

* Local LLM inference through Ollama
* faster-whisper speech recognition
* Piper local text-to-speech
* Screen and face awareness
* Multi-agent architecture
* ChromaDB semantic memory
* Browser automation
* Desktop and device control
* Proactive companion behaviour
* Gmail / Calendar integrations
* Discord integration
* Permission gates and audit logs
* Animated avatar and lip synchronization
* Request tracing and observability
